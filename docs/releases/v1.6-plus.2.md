# bbport-plus 1.6-plus.2

Test release. Based on upstream [windows-v1.6](https://github.com/Supermedo/bloodborne_pc/releases/tag/windows-v1.6)
(commit `e076119`); the native game runtime is unchanged. It contains everything of 1.6-plus.1 (Chinese language,
a log per run, crash reports, frame-drop records, system-language default) plus the changes below.

## What's new since 1.6-plus.1

- **A crash needs no action from you.** When the game ends abnormally, the crash report is written and the folder with
  it opens by itself, with the file selected. Nothing to start, nothing to confirm.
- **Mods are supported, and chosen in the launcher.** *Mods & patches* lists every folder in `mods\`; tick the ones that
  should load and set their order. A `mods\README.txt` explains the folder layout.
- `Install-BBportPlus.ps1 -ModsZip <pack>` installs a mods pack of your own (made with
  `packaging\windows\make_mods_pack.ps1`), for moving your mods to another PC. **bbport-plus includes no mods**: they change
  the game's own files and belong to their authors.
- The standalone crash-history script is no longer in the release; *Advanced → Collect crash history* does the same.

How to read the log files: `docs/DIAGNOSTICS.md`.

## Install

Download `Install-BBportPlus.ps1`, then in PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-BBportPlus.ps1 -Destination D:\Games\bbport-plus
```

It downloads the official upstream v1.6 package, checks its SHA-256, downloads the overlay of this release, checks that
too, and puts the launcher over the package. The destination must be on an **NTFS** drive. Add
`-ModsZip D:\my-mods-pack.zip` to install a mods pack at the same time.

By hand: unpack the upstream `Bloodborne-Windows.zip`, then unpack `bbport-plus-1.6-plus.2-overlay.zip` over the
`bbport-windows` folder (replace `Bloodborne.exe` and `_internal`).

You need your own decrypted dump of Bloodborne, version 1.09. **No game files are included.**

## Please test

- Play as usual. If the game closes by itself, the crash report folder opens; send the `crash_<time>.txt` in it.
- If it stutters or drops frames, send `perf_events.log` and the newest `run_<time>_stalls.log` from `<saves folder>\logs\`.
- Say which graphics card and driver you use; AMD owners especially (some AMD cards crash when the world loads).

## Known limits

- The crash report's *fault lines* part is untested on a real crash so far; it has been checked with a simulated one.
- DLSS needs `nvngx_dlss.dll`, which only comes with the upstream package.

## Files

| `SHA256SUMS.txt` | SHA-256 of the two files above |
