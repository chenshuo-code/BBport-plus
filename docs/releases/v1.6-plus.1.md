# bbport-plus 1.6-plus.1

First test release. Based on upstream [windows-v1.6](https://github.com/Supermedo/bloodborne_pc/releases/tag/windows-v1.6)
(commit `e076119`); the native game runtime is unchanged. This release is for **testing**: please report what you see.

## What's new

- **Chinese (Simplified, Traditional) and Korean** in the launcher's *Game language* list.
- **A log for every run.** Upstream overwrote `last_run.log` on each start, so after a crash the evidence was gone as
  soon as you started the game again. Logs now go to `<saves folder>\logs\`, the last 40 runs are kept.
- **Automatic crash report** (`crash_<time>.txt`) when the game ends abnormally: exit code, the runtime's fault lines,
  the last output, GPU and memory state, graphics adapters, and the matching Windows event log entries (application
  errors, graphics driver resets, low memory). After a `Play Bloodborne.exe` run a message box shows where it is.
- **Frame-drop and stutter records**: every fall from a steady 55+ FPS to under 40 (`perf_events.log`), and every frame
  over 40 ms with the game's own breakdown (`..._stalls.log`: shader compiles, texture uploads on map changes).
  Works on any graphics card; NVIDIA cards also log temperature, power and throttle reasons.
- `Bloodborne.exe --diag-report` and `tools\Collect_Crash_History.bat`: export what Windows recorded about earlier
  crashes and driver resets.
- The game language starts out as your Windows display language (a Chinese Windows gets Chinese), and a language you
  picked yourself is kept.
- The update check now looks at this project's releases and only opens the release page.

How to read the files: `docs/DIAGNOSTICS.md`.

## Install

Easiest: download `Install-BBportPlus.ps1`, then in PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-BBportPlus.ps1 -Destination D:\Games\bbport-plus
```

It downloads the official upstream v1.6 package, checks its SHA-256, downloads the overlay of this release, checks
that too, and puts the launcher over the package. The destination must be on an **NTFS** drive.

By hand: unpack the upstream `Bloodborne-Windows.zip`, then unpack `bbport-plus-1.6-plus.1-overlay.zip` over the
`bbport-windows` folder (replace `Bloodborne.exe` and `_internal`).

You need your own decrypted dump of Bloodborne, version 1.09. **No game files are included.**

## Please test

- Play as usual and, if the game closes by itself, send `crash_<time>.txt` from `<saves folder>\logs\`.
- If it stutters or drops frames, send `perf_events.log` and the newest `run_<time>_stalls.log`.
- Say which graphics card and driver you use; AMD owners especially (some AMD cards crash when the world loads).

## Known limits

- The crash report's *fault lines* part is untested on a real crash so far; it has been checked with a simulated one.
- DLSS needs `nvngx_dlss.dll`, which only comes with the upstream package.
