# bbport-plus 1.6-plus.3

Test release. Based on upstream [windows-v1.6](https://github.com/Supermedo/bloodborne_pc/releases/tag/windows-v1.6)
(commit `e076119`); the native game runtime is unchanged. It contains everything of 1.6-plus.1 and 1.6-plus.2.

This release exists to find out why the game crashed on one AMD PC: an access violation inside `ucrtbase.dll`, 79
minutes after Windows had flagged the process for a memory leak. Windows flagged the same process on an NVIDIA PC as
well, so the cause is probably in the runtime, not in a graphics driver. That the leak leads to the crash is a guess
until these measurements show it.

## What's new since 1.6-plus.2

- **The game process is measured while you play.** `run_<time>_proc.csv` in `<saves folder>\logs\` has its private
  memory, memory in RAM, commit, thread count and handle count every 2 seconds. If the game leaks, one of these
  columns keeps growing (for example a step up at every map change). The last 40 samples are also in every crash
  report.
- **The OBS capture hook is switched off for the game** (setting *Switch off the OBS capture hook for the game*,
  on by default). OBS's Vulkan capture layer was loaded into the crashed process. Untick it if you capture the game
  with OBS *Game Capture*.

## Install

Download `Install-BBportPlus.ps1`, then in PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File .\Install-BBportPlus.ps1 -Destination D:\Games\bbport-plus
```

It downloads the official upstream v1.6 package, checks its SHA-256, downloads the overlay of this release, checks that
too, and puts the launcher over the package. The destination must be on an **NTFS** drive. You need your own decrypted
dump of Bloodborne, version 1.09. **No game files are included.**

## Please test

- Play as usual. If the game closes by itself, the folder with the crash report opens; send the `crash_<time>.txt` in it,
  and the `run_<time>_proc.csv` next to it.
- Say which graphics card and driver you use.

## Known limits

- The crash report's *fault lines* part is untested on a real crash so far; it has been checked with a simulated one.
- DLSS needs `nvngx_dlss.dll`, which only comes with the upstream package.
